# 翻译与双语呈现

## 翻译优先级

- 改善流畅性前，先保留数学含义、逻辑强度、术语、公式、引用和标签。
- 使用自然的段落级翻译，不强行逐句机械对应。
- 英文保持简洁，优先使用主动语态和常用词，避免不必要的华丽词汇。
- 保留源文中已确定的技术术语和符号。

## 双语输出

- 用户要求作业或学术文本的双语版本时，按对应的自然段配对，而非逐句对应。
- 任务是术语、连接词或固定表达的复习列表时，使用标题为 `中文 | English` 的横向双列表格。
- 用户只要求单语翻译时，不额外添加双语排版。

## 质量检查

- 检查每个条件、否定、量词、比较和因果关系是否在翻译后得到保留。
- 不要用看似更流畅、但在数学上含义不同的短语替换精确技术术语。
- 源句有歧义时，标出歧义；不要悄悄选择会改变断言含义的解释。
