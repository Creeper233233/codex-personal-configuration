# 学术写作风格

## 通用风格

- 使用正式、简洁、精确、客观的学术语言。
- 相比优雅措辞或修辞效果，优先保证数学或事实准确性、句法清楚和术语一致。
- 删除空泛修辞、陈词滥调、口语化填充、不必要的重复和缺少依据的评价性语言。
- 若拆分长句不损失逻辑关系，优先使用简短直接的句子。
- 保留作者原本的主张、断言强度和逻辑限定语。

## 中文学术写作

- 使用书面语而非口语。
- 当“事实上”“值得深入思考的是”或“也就是说”等表达没有增加逻辑内容时，避免使用它们。
- 避免过多口号化表达、套话和夸张。
- 中文语境中使用书名号 `《》`；若上下文采用英文标点风格，则保持标点一致。
- 在全文中保持技术术语稳定。

## 英文学术写作

- 优先使用短句、主动语态、常用词和清楚的主谓结构。
- 避免不必要的复杂词汇、冗长嵌套从句和装饰性同义词。
- 改善流畅性前，先保留数学含义。
- 保持术语一致；不要仅为追求表达变化而交替使用不同术语。
- 仅在逻辑连接词能澄清论证时使用它们。

## 修订与压缩

- 检查拼写、语法、标点、歧义、冗余、术语和一致性。
- 压缩时，先删除重复和信息量低的铺垫，再考虑删减定义、假设、证据或结论。
- 不要仅为缩短文本而削弱或加强数学或事实性断言。
- 对既有稿件，除非用户要求更大范围的重写，否则保留其符号、术语、章节结构、引用和文风。
