# 学术写作、LaTeX 与 TikZ

## 核心约束

- 将当前用户请求和当前稿件视为最高优先级；若其与本 Skill 冲突，以当前请求和稿件为准。
- 保留既定的记号、术语、标签、编号、文档结构和作者意图。
- 仅作满足请求所需的最小修改；不要悄悄重写未要求修改的内容。
- 不要从过往论文、课程或计算项目中带入术语、模板、引用命令或排版决定。
- 凡涉及正文内容的起草、改写、润色、校对、压缩或翻译任务，都读取 `references/writing-style.md`。
- 每次 LaTeX 或 `.tex` 任务都读取 `references/latex-rules.md`。
- 每次 TikZ、`tikzpicture` 或学术图示任务都读取 `references/tikz-rules.md`。
- 仅在翻译、双语对照或术语列表任务中读取 `references/translation-style.md`。

## 工作流程

1. 确定所需操作：起草、修订、校对、压缩、翻译、编辑 LaTeX，或创建、修改 TikZ 图形。
2. 锁定受保护元素：数学含义、事实性断言、记号、术语、引用、标签、编号、TikZ 坐标与几何关系，以及未要求改变的结构。
3. 以最小且连贯的改动提高正确性、清晰度、简洁性和一致性。
4. 重新检查，确保没有意外改变数学条件、逻辑限定语或引用关系。
5. 按用户要求的格式交付；可直接复制的 LaTeX 或 TikZ 使用带 `latex` 语言标记的围栏代码块，或写入相应的 `.tex` 文件。

## 编辑边界

- 不要仅因另一种符号或术语看起来更常见就直接改动；先询问用户或标出问题。
- 不要虚构事实、参考文献、引文、引用键或书目信息。
- 当差异重要时，区分“必要纠正”和“可选的风格改进”。
- 对范围狭窄的编辑，除非用户明确纳入范围，否则不改标题、作者、注释、宏包、参考文献样式或文件结构。

## 与数学任务协同

- 若写作、LaTeX 或 TikZ 任务同时需要数学推导、证明构造、反例或数学正确性审查，则同时使用 `guide-math-learning`。
- 语言、翻译、排版和图形呈现由本 Skill 负责；数学正确性由 `guide-math-learning` 负责。

## 规范维护

- 当用户明确表达“以后”“默认”“统一”“始终”等长期、跨项目适用的写作、翻译、LaTeX 或 TikZ 偏好，或同一偏好反复出现时，主动提醒该要求可能适合加入本 Skill，并说明建议修改的文件和理由。
- 不把一次性要求、特定论文要求或项目专属规则建议为全局规范。
- 只判断写作、翻译、LaTeX 和 TikZ 范围内的规范；若同时使用 `guide-math-learning`，不要重复提醒其负责的数学学习或证明偏好。
- 未经用户明确同意，不修改本 Skill 或其引用文件。

- `references/latex-rules.md`：标点、公式、交叉引用、伪代码、`cases`、导言区与输出规则。
- `references/tikz-rules.md`：学术图示选择、黑白打印、坐标保护、宏包与布局规则。
- `references/translation-style.md`：段落级双语输出和术语表规则。
