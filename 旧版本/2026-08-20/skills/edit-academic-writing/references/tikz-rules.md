# TikZ 图形与插图规则

## 适用范围与优先级

- 将当前用户指令和当前源文件视为最高优先级。
- 仅使用当前任务提供的图形语义、术语、坐标和样式；不要从过往论文、答辩或其他项目中带入图号、标签、固定坐标或专属构造。
- 将本文件用于 TikZ、`tikzpicture`、论文示意图、图论结构图和算法流程图的创建、修改与审查。

## 图形选择与表达

- 学术论文中适合使用矢量图表达的示意图优先采用 TikZ；当前模板、源文件或用户要求采用其他方式时，以当前材料为准。
- 使图形服务于定义、构造、关系、冲突判别或算法过程的说明，避免与论述无关的装饰。
- 兼顾黑白打印；优先使用线型、花纹和标记区分对象，不要只依赖颜色传递信息。
- 在同一图或同组图中保持顶点、边、箭头、线宽、字体和标签样式一致。

## 坐标与几何保护

- 将当前源文件中的坐标、节点位置、路径、标签位置、缩放比例和相对几何关系视为受保护内容。
- 不要仅为视觉偏好随意移动节点、改变坐标或重排图形。
- 除非当前请求已经明确授权调整，否则必须改变坐标或图形位置时，先说明原因、影响范围和建议方案，并取得用户同意。
- 能通过添加线型、花纹、标记、图层或外围布局解决问题时，优先保留原有几何结构。
- 绘制图论结构时，避免边线穿过顶点文字；保持线宽统一，并调整边标或节点标签以避免压线和重叠，但不要借此擅自改变已锁定坐标。

## 宏包与 TikZ 库

- 遵守 `references/latex-rules.md` 的导言区边界；未经用户明确要求，不直接修改导言区。
- 需要新增 TikZ 支持时，先检查模板是否已经加载 `tikz` 和所需库，避免重复加载或引入冲突。
- 常用库包括 `arrows.meta`、`positioning`、`calc`、`fit`、`backgrounds`、`patterns` 和 `decorations.markings`；仅按当前图形实际需要加载，不要机械地全部加入。
- 若任务确实需要修改导言区，列出需要添加或替换的精确命令，并说明用途。

## 缩放与跨文档重用

- 图形过宽时，优先整体缩放、调整外层容器或列宽，不要直接修改内部坐标。
- 适合时可使用 `\resizebox{\textwidth}{!}{...}`；使用前确认当前文档已经具备相应支持，且缩放不会使文字难以辨认。
- 将论文图形重用于 Beamer 或其他文档时，优先复用原始 TikZ 代码，并通过缩放、容器或列宽适配版面。

## 检查与交付

- 检查 `tikzpicture` 环境、花括号、路径终止符、样式名称、所需库、绘制顺序和标签是否一致有效。
- 修改现有图形后，确认未意外改变坐标、数学含义、对象对应关系或黑白可辨识性。
- 在聊天中交付可直接复制的 TikZ 代码时，使用带 `latex` 语言标记的 Markdown 围栏代码块；针对工作区文件时，优先更新实际文件并提供文件引用。
